# RECIPE BUILDER

## Features
- View a pantry of ingredients with calories, protein, carbs, and fat (per 100g)
- Add ingredients to a recipe
- Change the number of grams for each ingredient
- Automatically calculate total nutrition for the recipe
- Support a vegetarian recipe type that prevents adding meat
- Save recipes using localStorage
- Load and delete saved recipes
- Add new ingredients to the pantry

## Assumptions
- All nutrition values are given per 100g.
- Ingredient amounts are entered in grams.
- Recipes are saved in the browser using localStorage.
- Vegetarian recipes should not include ingredients categorized as meat.

## AI Usage
- I used chatGPT to help explain errors and suggest small code changes during development.
